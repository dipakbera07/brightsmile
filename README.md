# BrightSmile Family Dentistry — Next.js demo

A reference-informed frontend clone/redesign using the demo business details from row 26 of the supplied website sheet.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Reference-informed features

The reference site at https://www.austindentalco.com/ includes a virtual consultation flow, membership-plan content, dentist/team profiles, patient testimonials, an office gallery, a fear-free treatment approach, featured treatments, dental insurance information, community/news content, service categories, patient resources, and location navigation. This demo adapts those content patterns to the fictional BrightSmile brand.

### Services included

Sedation Dentistry, Preventive Dentistry, Restorative Dentistry, Clear Aligners, Cosmetic Treatments, Invisalign®, Dental Implants, Teeth Whitening, Veneers, Dental Crowns, Emergency Dentistry, and Oral Surgery.

## Important demo limitations

- The business name, phone, email, address, and contact person are fictional demo details from the supplied sheet.
- The reference site's exact services and content structure informed the navigation and page coverage. Do not copy its original logo or claim affiliation.
- Any unverified treatment, team, membership, insurance, location, or pricing content is illustrative. No real patient reviews, credentials, treatment outcomes, or insurance acceptance are claimed.
- Appointment/contact forms are demo-only unless a real backend is added. Do not send sensitive patient information through this demo.
- Emergency dentistry information is not emergency care; contact a qualified provider or local emergency services when needed.
